# AkTextToVoice — Kaggle RVC Training

Notebook: `notebooks/AkTextToVoice_RVC_Kaggle.ipynb`

1. Open the notebook in Kaggle.
2. Enable GPU in notebook settings.
3. Add your own recordings through a private Kaggle Dataset.
4. Review the recordings and remove clips with other speakers, background music, noise or corrupted audio.
5. Run the notebook cells in order.
6. Complete preprocessing, feature extraction, training, export and held-out inference testing in Applio.

The GitHub Pages site is the public frontend. Model training and audio inference require a separate running compute backend. Kaggle sessions are temporary and have usage limits.

Never commit private source recordings to this public repository.
